# Simple AI Chat Assistant

A lightweight, terminal-based AI Chat Assistant built with Python using the official Google Gemini API (`google-genai` SDK). It maintains conversation context, allowing for natural, back-and-forth dialogue directly inside your command-line interface.

## Prerequisites

Before running the project, ensure you have the following installed:
- Python 3.10 or higher
- A Gemini API Key (You can get a free key from Google AI Studio)
